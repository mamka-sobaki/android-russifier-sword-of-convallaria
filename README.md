# Android Русификатор — Sword of Convallaria

Неофициальный Android-патчер для игры Sword of Convallaria. Он устанавливает подготовленный русский перевод в Lua-бандлы игры через Shizuku. Патчер проверяет версию ресурсов перед изменением файлов и содержит соответствующие оригиналы для возврата.

Проверенная конфигурация выпуска — игра `2.10.0.23603`, ревизия ресурсов `6401463`. APK также определяет стандартную папку игры на Android и расположение игры внутри GBox. Устройство должно разрешать работу Shizuku с игровыми файлами. Минимальная версия Android — 8.0, API 26.

## Установка

1. Установите Shizuku из [официальной страницы загрузки](https://shizuku.rikka.app/download/).
2. Запустите Shizuku. На Android 11 и новее можно включить «Для разработчиков» и «Беспроводную отладку», выполнить сопряжение по коду и нажать «Запустить» в Shizuku. Запуск Shizuku через ADB требуется повторять после перезагрузки устройства.
3. На Android 8–10 запустите Shizuku с компьютера по официальной инструкции приложения Shizuku.
4. Установите APK патчера. При первом действии разрешите ему доступ Shizuku.
5. Запустите игру через GBox или обычный значок и дождитесь завершения загрузки ресурсов.
6. Полностью закройте игру, включая её процесс внутри GBox, затем откройте патчер и нажмите «Установить перевод».
7. После сообщения об успешной установке запустите игру обычным для вашего устройства способом.

Чтобы вернуть оригинальные Lua-файлы, полностью закройте игру и выберите «Восстановить оригинал». Сделайте это **до удаления патчера**. Оригинальные файлы для восстановления входят в APK и архив исходников.

Если версия игры или содержимое целевых файлов отличается от проверенной ревизии, патчер прекращает операцию. Перевод для другой ревизии этим выпуском не заявлен.

## Источник перевода

Переводная память и русские тексты основаны на проекте [Anothery/sword-of-convallaria-rus](https://github.com/Anothery/sword-of-convallaria-rus). В этой работе готовый перевод перенесён в Lua-бандлы ревизии `6401463` с сохранением таблиц и ключей обновлённых ресурсов.

## Сборка

Для сборки нужны Android SDK Platform 34, JDK 17 и Gradle 8.14.7. Из каталога проекта выполните:

```text
gradle :app:assembleDebug
```

Debug APK подписан отладочным ключом для тестирования. Для публикации в качестве официального релиза приложения соберите и подпишите APK собственным ключом релиза.
