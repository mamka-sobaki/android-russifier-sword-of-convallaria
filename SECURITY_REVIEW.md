# Проверка пакета публикации

Проверен подготовленный исходный проект и текстовые файлы релиза.

- Поиск по исходникам и описаниям на предмет API-ключей, секретов, паролей, токенов и ключей подписи не выявил совпадений с шаблонами секретов.
- В пакет не включены `local.properties`, пользовательские каталоги SDK, Gradle-кэши, временные файлы сборки, логи устройства, снимки экрана, резервные копии с устройства и диагностические APK.
- Отладочный APK использует стандартный Android debug certificate. Он не содержит пользовательский ключ релиза.
- APK и исходный ZIP содержат оригинальные игровые Lua-бандлы для функции восстановления. Владелец подтвердил право на их публичное распространение; независимая юридическая проверка прав не проводилась. Эти файлы не покрываются Unlicense.
- Репозиторий и релиз v1.3.0 опубликованы публично: README, документы, Unlicense, APK и ZIP исходников доступны всем.
